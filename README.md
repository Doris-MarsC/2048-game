# 2048 游戏

一个使用原生 HTML、CSS 和 JavaScript 实现的网页版 2048 小游戏。无需任何构建工具或依赖，直接用浏览器打开 `index.html` 即可运行。

## 项目简介

本项目是经典益智游戏 2048 的网页实现。玩家通过方向键或 WASD 移动棋盘上的数字方块，相同数字的方块相撞时会合并为更大的数字，目标是合成出 2048。

项目全部逻辑由纯前端技术编写，代码不依赖任何第三方库或框架。

## 功能介绍

- **4×4 棋盘**：以网格形式展示 16 个格子，不同数字的方块拥有不同的背景颜色与字号。
- **方块移动与合并**：支持向上、下、左、右四个方向滑动。相同数字在滑动方向上相撞会合并为一个新方块，且每个方块在一次操作中最多只合并一次。
- **随机生成方块**：每次有效移动后，会在随机空格生成一个新方块，其中 90% 概率为 2，10% 概率为 4。
- **分数统计**：实时显示当前分数，每次合并都会把合并后的数值累加到总分（例如两个 2 合并为 4 时加 4 分）。
- **重新开始**：点击「重新开始」按钮可随时开启新的一局。
- **胜利提示**：当首次合成出 2048 时，会弹出「恭喜你，达成 2048！」的提示，玩家可以选择「继续游戏」挑战更高分数。
- **失败判定**：当棋盘既没有空格、也没有可合并的相邻方块时，弹出「游戏结束！」提示，并可点击按钮重新开始。

## 运行方法

项目为纯静态页面，无需安装依赖或启动服务器。

1. 下载或克隆本项目到本地。
2. 用浏览器（Chrome、Firefox、Edge 等）直接打开项目根目录下的 `index.html` 文件。
3. 页面加载后即自动开始一局新游戏。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 向上移动 | `↑` 或 `W` |
| 向下移动 | `↓` 或 `S` |
| 向左移动 | `←` 或 `A` |
| 向右移动 | `→` 或 `D` |
| 重新开始 | 点击「重新开始」按钮 |

说明：

- 只有能够真正移动或合并方块的按键操作才会生效；无效方向的移动不会生成新方块。
- 达成 2048 后点击「继续游戏」可关闭胜利提示继续游玩。
- 出现胜利或失败提示遮罩时，暂时无法移动方块，需要先点击提示框中的按钮。

## 项目结构

```
2048-game/
├── index.html   # 页面结构：游戏标题、分数面板、棋盘容器、遮罩层及按钮
├── style.css    # 页面样式：整体布局、棋盘网格、各数字方块配色、遮罩层样式
├── script.js    # 游戏逻辑：棋盘数据、移动与合并算法、计分、胜负判定与渲染
└── README.md    # 项目说明文档
```

各文件作用：

- **index.html**：定义页面骨架。包含标题、分数显示区、重新开始按钮、用于渲染棋盘的 `#board` 容器，以及用于显示胜利/失败提示的遮罩层 `#overlay`。通过 `<link>` 引入样式表，通过 `<script>` 引入脚本。
- **style.css**：负责全部视觉表现。使用 CSS Grid 将棋盘划分为 4×4 网格，通过 `.tile-2` 到 `.tile-2048` 以及 `.tile-super` 等类名为不同数字设置颜色和字号，并定义遮罩层的显示与隐藏。
- **script.js**：游戏核心逻辑。使用一维数组存储棋盘（`索引 = 行 × 4 + 列`，`0` 表示空格），实现向左滑动与合并的基础算法，并基于行列变换实现四个方向的移动；同时负责计分、随机生成方块、胜负判定、键盘事件监听以及页面渲染。

## 开发技术

- **HTML5**：构建页面结构与语义化标签。
- **CSS3**：使用 Grid 布局、Flex 布局、`aspect-ratio` 等比棋盘以及过渡动画。
- **JavaScript（原生 ES5 风格）**：实现游戏全部逻辑，采用立即执行函数（IIFE）与严格模式组织代码，不依赖任何第三方库。
